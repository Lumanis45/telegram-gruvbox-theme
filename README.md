# Gruvbox for Telegram Desktop

Dark theme for the official Telegram Desktop client. Palette: [colors.scss](colors.scss).

Settings → Chat settings → Choose from file → [gruvbox.tdesktop-theme](gruvbox.tdesktop-theme).

| Role | Color |
|---|---|
| Window, lists, compose | `#282828` |
| Chat background | `#1d2021` |
| Hover, incoming bubble | `#3c3836` |
| Active row, selection | `#504945` / `#665c54` |
| Text / secondary | `#fbf1c7` / `#a89984` |
| Accent, outgoing bubble | `#458588`, bubble `#3c6e71` |
| Accent hover | `#54c2c7` |
| Error / success / warning | `#cc241d` / `#b8bb26` / `#fabd2f` |
